#Мини‑Склад — учебный проект на 1С:Предприятие 
Реализован минимальный контур складского учёта: поступление и расход товаров, контроль остатков, отчёт по остаткам, базовая обработка загрузки данных. 
Проект показывает навыки работы с документами, регистрами накопления, формами, расширениями и Git.

## Что внутри проекта

### Объекты конфигурации
- **Справочники**: `Товары`, `Склады`.
- **Документы**: `ПоступлениеТоваров`, `РасходТоваров`.
-
- ### Логика
- При проведении `ПоступлениеТоваров` создаются движения по регистру `ОстаткиТоваров`: `КоличествоПриход = КоличествоВДокументе`.
- При проведении `РасходТоваров` проверяется остаток: если товара недостаточно — выдаётся отказ проведения. Движения: `КоличествоРасход = КоличествоВДокументе`.
- Отчёт берёт данные из виртуальной таблицы `ОстаткиТоваров.Остатки`.

## Как открыть и запустить проект

### Вариант 1: из файловой выгрузки (рекомендуется для Git)

1. Создайте новую пустую информационную базу 1С (файловую).
2. Откройте базу в режиме **Конфигуратор**.
3. В меню: `Конфигурация → Загрузить конфигурацию из файлов…`
4. Укажите папку `src` из репозитория.
5. Если есть расширения — подключите их через `Конфигурация → Расширения конфигурации`.
6. Нажмите `F7` (**Обновить конфигурацию базы данных**).
7. Запустите в режиме **1С:Предприятие** и проверьте сценарии.
    
### Вариант 2: из файла `.cf`

1. Откройте базу в **Конфигураторе**.
2. `Конфигурация → Загрузить конфигурацию из файла…`, выберите `.cf`.
3. Нажмите `F7`.
4. Запустите в режиме Предприятия.

> ⚠️ Перед любыми действиями обязательно сделайте **бэкап** базы (выгрузка в `.dt`). Это критично для стажировки и реальных баз.

## Где смотреть конфигурацию в 1С

- В режиме **Предприятия**: `Администрирование → Информация о программе` — там указана версия и название конфигурации.
- В **Конфигураторе**: дерево конфигурации слева — полный список объектов.
